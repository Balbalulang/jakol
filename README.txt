SKATE SHOP FRONTEND WEBSITE

Files:
- index.html: page structure and Bootstrap imports
- styles.css: custom dark skate-shop styling and responsive layout
- script.js: carousel drag, product search, cart, and contact form storage
- assets/: your uploaded images assigned to the requested sections

HOW TO RUN
1. Extract the ZIP file.
2. Open the skate-shop-website folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Internet is required for Bootstrap CDN, Bootstrap Icons, and Google Fonts.

FRONTEND-ONLY NOTES
- Cart items are stored in localStorage under skateShopCart.
- Contact form submissions are stored in localStorage under skateShopMessages.
- No server, database, authentication, or payment processing is connected.
- Replace the sample contact phone, email, and Facebook page with your actual details.
- Edit product names and prices in index.html.
